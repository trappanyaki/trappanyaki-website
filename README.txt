# Trappanyaki Landing Page Deployment

1. **ZIP Contents:**
   - index.html (Main Page)
   - MASCOT.png
   - images/ (Optimized assets)
   - thumbnails/ (Video poster frames)
   - videos/ (Hero background clip)

2. **Deployment Instructions:**
   - **Netlify:** Log in, go to 'Sites', and drag the extracted folder (or the ZIP) directly into the deployment area.
   - **Custom Domain:** Under 'Site Settings', add your domain and enable HTTPS.

3. **Contact Setup:**
   - The 'Book Now' button currently triggers a mailto: to TrappanyakiLLC@gmail.com.
   - For a contact form, use Netlify Forms by adding 'netlify' to the form tag.

4. **Credits:**

   - FontAwesome for icons.
